# 한눈 — 번역 없이 문화를 비교하는 AI 비전 팀플 도구

각국 현장 이미지를 객체 탐지 AI가 같은 기준으로 측정하고, 현지 출신 팀원이 그 차이를 해석하도록 돕는 다문화 팀플 조사 도구입니다.
2026 HUSS 「AI를 활용한 어울림 공모전」 **최우수상(1등)** 출품작입니다.

## 문제 정의 / 동기
- 외국인 유학생이 포함된 팀플에서 유학생이 모국어로 조사한 자료는 번역을 거치며 "해외 사례" 부록으로 밀려나는 경우가 많습니다.
- 원인을 세 가지로 보았습니다: 글 자료에 필요한 번역의 거리감, 나라마다 다른 조사 기준, 발표 직전에 각자 자료를 이어 붙이는 구조.
- 사진·영상은 번역 없이 비교할 수 있으므로, 같은 AI의 눈으로 측정하면 외국 자료도 한국 자료와 같은 차트 위에 올릴 수 있다고 보았습니다.

## 접근 방식
- **수집:** 한국·일본·베트남 현지어 검색어로 편의점 매장 영상을 모으고, 다른 나라 지명이 섞인 영상은 걸러 냄
- **전처리:** 초당 1프레임 추출 → 선명도 점수로 흔들린 프레임 제거 → 유사 프레임 중복 제거
- **탐지:** COCO 사전학습 YOLO 모델을 로컬에서 돌려 사람·의자·테이블·컵·노트북·오토바이 등을 탐지
- **지표화:** 박스 겹침·거리 규칙을 직접 설계해 "머무름·함께 옴·공부·식사·설비·이동 수단" 6개 생활 지표로 환산
- **비교·검수:** 국가별 레이더 차트와 대표 장면 비교, 무작위 표본을 직접 검수해 탐지 정밀도 공개
- **프로토타입:** 지표 비교와 현지 팀원 해석 카드를 묶은 웹 프로토타입과 시연 영상 제작

## 본인 역할
개인 참가: 기획, 데이터 수집 파이프라인, 탐지·지표 설계, 시각화, 프로토타입, 발표를 모두 담당

## 사용 기술
Python · YOLO(Ultralytics) · OpenCV · pandas · matplotlib · yt-dlp · HTML/JS

## 구성
```
*.py      01~04 수집·프레임 추출·탐지·지표 계산, 05~16 발표 자료·기획서·대본 생성
data/     영상 목록과 탐지·장면 분류 결과 (CSV)
output/   기획서·발표자료 PDF, 지표 요약, 그림, 프로토타입(HTML), 시연 영상
```

## 실행
```bash
pip install ultralytics opencv-python pandas matplotlib yt-dlp
python 01_영상수집.py      # 영상 목록의 영상을 data/video 에 받음
python 02_프레임추출.py
python 03_장면분류_탐지.py  # yolo11s.pt 는 처음 실행할 때 자동으로 받음
python 04_지표_시각화.py
```

## 데이터에 대해
- 원본 영상과 추출 프레임은 저작권 때문에 레포에 넣지 않았습니다. `data/영상목록.csv`의 유튜브 링크로 다시 받을 수 있습니다.
- 영상은 분석 목적으로만 사용했고, 출처는 발표 자료에 표시했습니다.
